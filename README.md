# TransitOps - Odoo Hackathon

TransitOps is a transport operations management platform for fleet owners, logistics teams, and transport coordinators. The goal is to centralize vehicles, drivers, trips, maintenance, fuel usage, expenses, and operational dashboard insights in one full-stack application.

## Project Structure

```text
transitops-hackathon-odoo/
├── client/       # React frontend
├── server/       # Backend API
├── database/     # Schema, migrations, and seed data
├── docs/         # API contracts, rules, testing notes, and demo script
└── PROJECT_PLAN.md
```

## Core Modules

- Authentication and user access
- Vehicle management
- Driver management
- Trip planning and tracking
- Maintenance records
- Fuel logs
- Expense tracking
- Dashboard analytics
